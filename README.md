# Auth UI – Signup & Signin Pages

A simple and clean authentication UI built using **HTML, CSS, and JavaScript**.  
Includes **Sign Up** and **Sign In** pages with basic client-side validation.

---

## 🌐 Live Demo
- **Sign Up Page (Start Here):**  
  https://nageshl-12.github.io/auth-ui-signin-signup/

- **Sign In Page:**  
  https://nageshl-12.github.io/auth-ui-signin-signup/SignIn.html


---

## ✨ Features
- Responsive signup & signin design
- Email and password validation
- Works on both pages using a single JavaScript file
- Google, Facebook, and Apple button placeholders
- Clean UI suitable for portfolio projects
